## Sobre mim

Sou Desenvolvedor Full Stack, estudante de **Análise e Desenvolvimento de Sistemas**, com formação prevista para dezembro de 2026. Meu foco é desenvolver interfaces profissionais e acessíveis, APIs bem estruturadas, autenticação, bancos de dados e regras de segurança aplicadas a produtos reais.

Atualmente trabalho principalmente com **Next.js, React, TypeScript, Node.js, NestJS, PostgreSQL e Supabase**. Tenho interesse especial em aplicações SaaS, automação e recursos com inteligência artificial.

- 📍 Poços de Caldas, Minas Gerais — Brasil
- 💼 Aberto a oportunidades como Desenvolvedor Full Stack, Front-end ou Back-end
- 🔐 Experiência com autenticação, rotas protegidas, RLS e controle de acesso por perfil
- 🤖 Desenvolvimento de integrações com APIs e inteligência artificial
- 📚 Inglês intermediário
